# 早报文案更新

📝成语角\-\-前车之鉴

【释义】：前车：前面的车子；鉴：镜子。前面车子翻了的教训。比喻从前人的失败中得来的教训。



📝成语角\-\-姗姗来迟

【释义】：旧时形容女子走路迟缓从容的样子。形容慢腾腾地来晚了。



📝成语角\-\-因材施教

【释义】：因：根据；材：资质；施：施加；进行；教：教育。根据学习的人的不同志趣、资质来进行不同的教育。



📝成语角\-\-功亏一篑

【释义】：（筑九仞高的土山）由于只差一筐土而没有完成。比喻一件事情只差一点而没有成功。



📝成语角\-\-踌躇满志

【释义】：从容自得的样子；满：满足；志：心意。形容心满意足或十分得意的样子。多指对己所得的成就十分得意。



📝成语角\-\-纸上谈兵

【释义】： 在纸上谈论用兵（兵：打仗；用兵）。比喻不解决实际问题的空谈。
