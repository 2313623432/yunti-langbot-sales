# 猿辅导清洗版知识库交付包

包含 FAQ、销售话术、1天2次群发 SOP、课程货盘、QA 对的正式入库文件，以及 LangBot 模板目录。

## 推荐用法

1. 文档型知识库：上传 `langbot_template_pack/documents/*.md` 或 `faq_talk_ready` / `sop_ready` 中的 Markdown。
2. 结构化知识库：使用 `faq_talk_ready/*.jsonl`、`faq_talk_ready/*.csv`、`sop_ready/*.jsonl`、`sop_ready/*.csv`。
3. LangBot 项目：本仓库已把 `src/langbot/resources/templates/course-sales/yuanfudao-knowledge` 替换为清洗版模板。

## 缺口

- 价格、赠品、包邮、名额、退款、排期需要以后续最新活动页/班主任通知/系统后台为准。
